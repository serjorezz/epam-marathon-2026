* **Signals & Reactivity:** The project follows signals-first patterns (see [signals-migration.md](frontend/restaurant-frontend-app/docs/signals-migration.md)). Use `signal()`, `computed()`, `input()`, and `output()`. No new `Subject`/`BehaviorSubject` for UI state. In Angular 22, create `effect()` within an injection context. Convert streams via `toSignal()` for template rendering.
